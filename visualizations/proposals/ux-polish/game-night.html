A separate game mode. Tournament chips never become cash-out stacks. Prize pool, placements, unpaid entries and payout receipts stay auditable.

Keep the scope focused

No chip-count cash-out or cash drawer. Existing exact balance checks stay; an unbalanced cash table still cannot close.

Collect now, analyse later

Capture game type, stakes, confirmed buy-in times and actual play intervals first. Insights follow in phase 2 using the validated CSV contract. Never infer head-to-head winnings from net session results.

Handle interruption honestly

Production tournament clocks must recover from timestamps after screen lock or app closure. Call-time eligibility uses saved buy-in timestamps. It never automatically cashes a player out.

Design-only proposal. No app data is read, saved or shared.
